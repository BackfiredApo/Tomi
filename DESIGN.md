# Tomi Trading design

Tomi is a B2B manufacturing and sourcing site. Make the product ranges easy to scan, the production scope concrete, and the catalogue and quote links easy to find.

## Colour and typography

| Role | Value |
| --- | --- |
| Page background and raised surfaces | `#ffffff` white |
| Section background | `#f3f6fa` cool grey |
| Headings and primary actions | `#172b46` navy |
| Footer and dark panels | `#0d1625` midnight navy |
| Panels' light actions | `#e4edf8` pale blue |
| Links, hover and focus | `#2b507a` blue |
| Body and supporting text | `#202c3e` and `#4b5c71` |
| Dividers | `#d9e0ea` |

Set page and section headings in regular Georgia, with system sans-serif for navigation, body copy, cards and form controls. Keep the hierarchy visible through type scale, spacing and contrast.

## Layout and imagery

- Share a content width and gutters between navigation, page sections and footer. Use the original Guangzhou skyline as the full-width homepage background, with a dark overlay behind the white headline. Use a text-and-image split for capability headers and stack it on narrow screens.
- Make the image the strongest element in each product tile. Use the same 3:2 crop, warm grey backdrop, soft directional light and neutral palette across the five AI-generated covers. Label cover art as illustration on detail pages. Use the catalogue PDFs for actual product and manufacturing examples.
- Use a compact photo-and-text list on narrow screens. On wider screens use an evenly spaced grid with a single divider under each tile. Use simple ruled rows for catalogue links and plain text sections for product scope.
- Use navy for the primary inquiry action, a border or text link for supporting actions, and pale blue for actions inside dark panels. Give every interactive target a visible keyboard focus state and keep hover motion optional.
